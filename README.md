# Urban Planning

A Codex skill for urban planning and urban design at neighborhood, street, and public-space scales. It helps turn local evidence into a practical plan for improving an existing place.

Use it to map barriers and daily routes, develop a coordinated set of interventions, and check what will work on site. The catalog covers walking, cycling, public transport, accessibility, placemaking, parks and play, urban greening, stormwater, everyday services, and long-term maintenance. It also covers phasing, public consultation, design competitions, and how to present a plan on a public website.

## Install

Clone the repository into your project's skills directory.

```sh
git clone https://github.com/daniilak/urban-planning.git .agents/skills/urban-planning
```

Ask Codex to use `$urban-planning` and give it the study boundary, the jurisdiction, and any survey, map, or photo material you have. The skill also works for reviewing an existing plan or its public website.

English edition of [small-area-masterplan](https://github.com/daniilak/small-area-masterplan).
